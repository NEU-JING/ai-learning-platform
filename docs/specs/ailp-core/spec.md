# AILP Core — AI 能力验证平台

> **基线版本**: v1.0
> **归档来源**: change 002-ailp-v4-refactor
> **归档时间**: 2026-06-14

---

## 1. 功能概述

AILP V4 从学习平台重构为 AI 能力验证平台，核心交付：
- 四级认证体系（L1-L4）
- 多维技能雷达
- 公开能力主页
- 混合执行沙箱（Layer A/B/C）
- 雇主验证 API

---

## 2. 详细需求

### R1: 四路径课程矩阵

**描述**: 根据用户目标角色提供四种差异化学习路径

**AC 列表**:

#### Scenario AC1: 目标选择与路径生成
- **WHEN** 新用户注册，选择目标"AI工程师"
- **THEN** 系统生成个性化路径：必修课程12门+选修3门+Capstone项目2个+预计14周

#### Scenario AC5: Fast Track 模式
- **WHEN** 用户选择"3个月内跳槽"目标，选择Fast Track模式
- **THEN** 生成8周密集路径，每天需完成2-3个实验

### R2: 四级认证体系

**描述**: 建立从L1到L4的能力验证等级

#### Scenario AC30: L1自动评定
- **WHEN** AI工程师路径用户完成12门必修课程，实验平均分85，申请L1认证
- **THEN** 系统自动评定通过，生成证书，可下载

#### Scenario AC31: L2项目评审
- **WHEN** 用户提交Capstone项目，AI初审通过+人工抽检通过
- **THEN** 获得L2认证，项目进入展示库

#### Scenario AC37: 证书数字签名防篡改
- **WHEN** 用户获得认证，下载证书PDF
- **THEN** 证书包含数字签名，可通过验证接口确认真伪

### R3: 技能雷达系统

**描述**: 10维分层技能模型，预计算+时间衰减

#### Scenario AC7: 10维分层技能模型
- **WHEN** 用户完成50个实验，系统计算技能分数
- **THEN** 生成10维雷达图

#### Scenario AC10: 时间衰减计算
- **WHEN** 用户近期完成高阶段实验
- **THEN** 旧数据权重降低，新数据权重提高

### R4: 公开能力主页

#### Scenario AC43: 路径感知主页
- **WHEN** 用户开启主页
- **THEN** 突出显示对应路径的维度

### R5: 混合执行沙箱

#### Scenario AC38: 本地沙箱执行
- **WHEN** Phase 1实验提交执行
- **THEN** 在本地沙箱执行，返回结果，自动评分

### R6: 雇主验证 API

#### Scenario AC45: 验证URL+授权码
- **WHEN** 用户分享认证链接给雇主
- **THEN** 显示认证详情
